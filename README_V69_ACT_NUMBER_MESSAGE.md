# v69 — номер акта в сообщении без названия услуги

Изменения:
- Название услуги полностью убрано из автоматического сообщения об акте.
- Номер акта берётся из названия задачи проекта «Акты счета», если он там распознаётся.
- Поддерживаются, например: `АКТ №4 ...`, `АКТ № 4 ...`, `Акт выполненных работ №4 ...`, `АКТ 4 700р ...`.
- Формат вроде `АКТ 3Д КЛИМАТ ...` не считается актом №3.
- Если номер найден: `Направляем акт выполненных работ №4.`
- Если номера нет: `Направляем акт выполненных работ.`
- Остальной текст v68 сохранён: скан в течение 2 рабочих дней, оригинал в 2 экземплярах почтой, приветствие по времени Минска.
- Для кастомного `ACTS_CLIENT_MESSAGE` добавлены плейсхолдеры `{act_number}` и `{act_label}`; старый стандартный текст с «акт по услуге ...» автоматически нормализуется.
