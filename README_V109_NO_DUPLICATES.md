# v109 — жёсткая защита от повторных писем

Исправляет повторную отправку напоминания №1.

Причина: сообщения, видимые в правом «Чате задачи», не всегда возвращаются через task.commentitem.getlist. Из-за этого процесс мог не увидеть собственное подтверждение предыдущей отправки и снова отправить письмо №1.

В v109:
- dedupe читает и task.commentitem, и правый чат задачи через im.dialog.messages.get;
- письмо №1 блокируется при будущем дедлайне даже если комментарий временно не читается;
- перед SMTP выполняется повторная проверка этого же правила;
- обязательное вложение v108 сохранено;
- окно рассылки 08:00–19:00 по Минску сохранено;
- email-only и стадия «Ручная отправка» сохранены.
