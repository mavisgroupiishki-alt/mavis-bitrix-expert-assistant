# v115 — мгновенное открытие отчёта

Изменения:
- отчёт показывает локальный снимок сразу; ключ браузерного кэша сохранён между v114 и v115;
- кнопка «Обновить данные» больше не ждёт полную пересборку: обновление идёт в фоне;
- тяжёлый расчёт истории стадий по всем задачам больше не запускается автоматически при открытии;
- месячная динамика считается только по кнопке «Обновить динамику»;
- после deploy сервер ждёт 45 секунд перед фоновым warm-up, чтобы не конкурировать с первым открытием приложения;
- ручное редактирование строки больше не очищает готовый снимок отчёта.

Цель: обычное открытие и фильтрация — мгновенно; тяжёлые Bitrix-запросы — только в фоне/по запросу.
