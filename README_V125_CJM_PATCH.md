# Точечный патч для текущего v125

Этот пакет НЕ заменяет `server.js` старой версией. Он вносит только три уже выявленных исправления в ваш **актуальный v125**.

Что исправляет:
1. Блок 1 «Распределение»: список кандидатов ограничивается подтверждёнными экспертами `2052,1960,2192,2198`, чтобы в рекомендацию не попадали продажи и посторонние пользователи.
2. «Сбор информации»: исправлена ошибка, из-за которой эта стадия могла не добавляться в список стадий polling, когда одновременно найдена стадия «Эксперт назначен».
3. Блок 5: эскалация руководителю снова минимум через **14 дней**, а не через 7.

Что НЕ меняет:
- Wazzup и его проверку входящих файлов;
- контур актов;
- отчёт «Возврат оригиналов»;
- остальные изменения v100–v125;
- исключение/логику исторических сделок вне текущего кода.

## Как применить

Положите `apply_v125_cjm_fixes.js` рядом с вашим текущим `server.js`, затем:

```bash
node apply_v125_cjm_fixes.js
```

Скрипт:
- проверит, что патчит именно ожидаемые фрагменты;
- создаст `server.js.before_v125_cjm_fix.bak`;
- применит изменения;
- выполнит `node --check server.js`;
- если синтаксис сломан — автоматически восстановит исходный файл.

Можно указать путь явно:

```bash
node apply_v125_cjm_fixes.js /path/to/server.js
```
