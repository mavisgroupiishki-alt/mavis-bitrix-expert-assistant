# v53 — ИИгорь: антидубли уведомлений от бизнес-процессов

Что исправлено:

1. Когда эксперт выбирает прораба в одной сделке производства, ИИгорь по-прежнему проставляет этого же прораба во все активные сделки этой компании.
2. Но если из-за этих автопроставлений Bitrix снова запускает бизнес-процесс по соседним сделкам, ИИгорь пропускает такие повторные webhook-вызовы.
3. По умолчанию ИИгорь больше не пишет отдельный комментарий в каждую сделку, куда он автоматически проставил прораба. Это убирает 4–5 лишних уведомлений.
4. Основной комментарий остаётся в карточке прораба по исходной сделке, где эксперт вручную выбрал специалиста.

Новые переменные Render:

FOREMAN_ADD_PROPAGATION_COMMENTS=false
FOREMAN_SKIP_PROPAGATED_WEBHOOK_MINUTES=20

Оставить так:

FOREMAN_PROPAGATE_TO_COMPANY_DEALS=true
FOREMAN_AUTOMATION_ENABLED=false
FOREMAN_SUGGESTION_SCAN_ENABLED=false

Бизнес-процессы в Bitrix менять не нужно.
