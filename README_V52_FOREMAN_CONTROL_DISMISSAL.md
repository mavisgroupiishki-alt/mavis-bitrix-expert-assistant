# v52 — ИИгорь: после закрытия производства переводит прораба в «Контроль увольнения»

Что поменялось:

1. `/api/foreman/robot-linked` без изменений: при выборе специалиста в производстве переводит прораба в «Занят», пишет комментарий и проставляет прораба в активные сделки той же компании.
2. `/api/foreman/robot-closed` теперь после закрытия производственной сделки переводит прораба не в «Свободен», а в стадию из переменной:

```env
FOREMAN_STAGE_AFTER_CLOSE=C32:...
```

Можно также использовать alias:

```env
FOREMAN_STAGE_CONTROL_DISMISSAL=C32:...
```

Если переменная не задана, код попробует сам найти стадию по названию «Контроль увольнения». Если не найдёт — включит старую безопасную логику.

Важно: `FOREMAN_STAGE_FREE` не меняем. Она нужна для поиска реально свободных кандидатов.
