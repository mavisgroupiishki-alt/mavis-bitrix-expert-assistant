# v145 — ответы клиенту по актам

Изменения:
- единый обработчик входящих текстовых сообщений для всех сделок; отдельный Bobik-пилот из webhook отключён;
- после любого входящего ответа клиента актовые пуши блокируются, но состояние не удаляется до завершения действия;
- запросы «пришлите/переотправьте акт» реально ищут связанную задачу в проекте #36 и файл акта, включая старые состояния после рестарта;
- при успешной отправке акта клиент получает подтверждение;
- для старых сделок без in-memory push state добавлен fallback через CRM-привязку задачи D_<dealId>;
- успешные сделки не восстанавливаются в очередь актовых пушей;
- новые CRM-комментарии по входящим сообщениям/ответам не содержат технических marker/JSON.
