# v149 — Акты: новые закрытые сделки + AI-ответы

## Логика

1. Старые/исторические успешные сделки НЕ получают новые актовые пуши.
2. Новая сделка, которая закрывается после включения v149, получает обычный первый актовый пуш и далее стандартные напоминания.
3. Если клиент отвечает после отправки акта, дальнейшие автоматические пуши по этой сделке останавливаются.
4. AI продолжает обрабатывать сообщения клиента по акту даже после остановки push-state.
5. Если клиент просит прислать акт повторно, система ищет последнюю связанную актовую задачу в проекте «Акты счета» и отправляет найденный файл.
6. Если клиент просит отправить акт на email, используется email-контакт сделки.
7. Исторические сделки остаются доступными для AI-ответа, но не восстанавливаются в recurring push state.

## Cutoff

По умолчанию cutoff: `2026-09-04T08:00:00+03:00`.

Можно переопределить через Render:
`ACTS_PUSH_NEW_ONLY_AFTER_ISO=2026-09-04T08:00:00+03:00`

Важно: cutoff относится к времени первоначальной отправки акта (`sentAt`) при восстановлении состояния. Уже существующие старые push-state после деплоя не восстанавливаются.
