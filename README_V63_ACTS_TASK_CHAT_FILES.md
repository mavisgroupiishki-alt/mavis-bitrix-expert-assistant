# v63 — Акты: файлы из чата задачи

Исправление отправки актов из новой карточки задач Bitrix24.

Что изменено:
- `tasks.task.get` теперь явно запрашивает `CHAT_ID`;
- если `UF_TASK_WEBDAV_FILES` пуст, сервер читает последние сообщения чата задачи через `im.dialog.messages.get`;
- из `result.files` используются `name`, `id`, `date`, `urlDownload`;
- при нескольких файлах приоритет: файл с «АКТ» в названии, затем PDF/DOC, внутри группы — самый свежий;
- в лог добавлены `chatId`, источник файла (`task-webdav` / `task-chat`) и наличие URL;
- если webhook не имеет scope `im`, в логе будет точная ошибка вместо общего «нет файла».
