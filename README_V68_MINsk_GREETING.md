# v68 — приветствие по времени Минска

Добавлено динамическое приветствие для сообщений об актах.

Правила по часовому поясу `Europe/Minsk`:
- 09:00–11:59 — «Доброе утро!»;
- 12:00–16:59 — «Добрый день!»;
- с 17:00 — «Добрый вечер!».

Для времени до 09:00 используется «Доброе утро!», чтобы не отправлять ночное «Добрый вечер!».

Логика применяется и к стандартному сообщению, и к кастомному `ACTS_CLIENT_MESSAGE`. Для кастомного шаблона также поддерживается плейсхолдер `{greeting}`.
