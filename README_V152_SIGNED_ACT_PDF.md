# v152 Подписанный PDF для отправки актов

Когда задача проекта «Акты счета» переходит в «Сделано», сервис может отправить клиенту PDF, сформированный из DOCX акта. В PDF добавляется визуальная печать и подпись Мавис Групп из `assets/mavis-signature-stamp.png`.

Это визуальный штамп, а не криптографическая электронная подпись или КЭП с сертификатом.

## Включение в Render

```text
ACTS_SIGNATURE_ENABLED=true
ACTS_SIGNATURE_SOFFICE_PATH=/usr/bin/soffice
ACTS_SIGNATURE_ANCHOR_TEXT=М.П.
```

На сервере Render должен быть установлен LibreOffice Writer (`soffice`). До этого включать `ACTS_SIGNATURE_ENABLED` нельзя: контур безопасно остановит отправку с понятной причиной, но PDF создать не сможет.

Для разовой проверки вместо клиента можно временно добавить:

```text
ACTS_SIGNATURE_TEST_RECIPIENT=mavis.group@mail.ru
```

При этом все подписанные акты будут уходить только на указанный адрес, поэтому сразу после теста переменную нужно удалить и перезапустить сервис.

## Защитные условия

- Отправляется только DOCX, в котором найдена строка `М.П.`.
- Если рядом с «М.П.» уже есть графика подписи или печати, повторный штамп блокируется.
- Исходный DOCX из задачи не редактируется и не отправляется как fallback.
- Если не найден DOCX, якорь, визуальный штамп, LibreOffice или корректный PDF, клиенту ничего не отправляется.
- PDF уходит по SMTP; сервис трижды пытается сохранить идентичную MIME-копию в папке «Отправленные» Mail.ru и отдельно сообщает, если это не удалось.
- До SMTP в сделке записывается `[MAVIS_ACTS_SEND_PENDING]`. Если SMTP оборвёт соединение после передачи данных с неопределённым статусом, повтор блокируется до ручной проверки, чтобы не создать дубль; известные ошибки до передачи письма помечаются как разрешённые к повтору.
- После успешной отправки `[MAVIS_ACTS_SENT]` продолжает блокировать повторную отправку той же задачи.
- Для подписанного письма используется стабильный `Message-ID` из ID задачи и сделки.

## Локальная проверка

```bash
ACTS_SIGNATURE_ENABLED=true \
ACTS_SIGNATURE_SOFFICE_PATH="$(command -v soffice)" \
node --test test/acts-signed-pdf.test.js
```
