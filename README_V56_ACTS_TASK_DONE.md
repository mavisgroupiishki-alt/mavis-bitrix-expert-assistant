# v56 — акт обработан по стадии «Сделано» в проекте «Акты счета»

Добавлен обработчик:

```text
/api/acts/task-done?task_id={{ID}}
```

Логика:

1. Робот в проекте «Акты счета» срабатывает на стадии «Сделано».
2. Render получает ID задачи.
3. Проверяет, что задача из проекта `ACTS_PROJECT_ID=36`.
4. Находит ID производственной сделки из `UF_CRM_TASK`, описания или ссылки в задаче.
5. Читает вложенные файлы задачи, насколько их отдаёт Bitrix API.
6. Пишет комментарий в связанную сделку производства: задача по акту обработана, файлы найдены.

Важно: сам факт возврата физического оригинала по-прежнему считается только стадией «Архив». Стадия «Сделано» означает, что задача обработана и файл акта уже можно брать из задачи.
