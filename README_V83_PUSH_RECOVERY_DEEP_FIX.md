# v83 — автопуши актов: глубокое восстановление и защита от вечной паузы

Исправления:
- если маркер успешной отправки акта не находится в последних 300 комментариях сделки, выполняется глубокий поиск до 2000 комментариев;
- это важно для сделок с большим количеством автокомментариев/ошибок, где старый маркер мог уйти далеко вниз таймлайна;
- один и тот же нераспознанный входящий файл больше не продлевает 24-часовую паузу бесконечно;
- лог восстановления показывает причины пропуска состояний;
- лог цикла показывает deal/task для актов, по которым пуш уже просрочен.

Правило не менялось: первый пуш через 2 календарных дня после успешной отправки, Сб/Вс клиенту не пишем.
