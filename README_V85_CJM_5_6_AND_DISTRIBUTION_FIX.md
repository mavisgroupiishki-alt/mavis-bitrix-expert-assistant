# v85 — CJM блоки 5–6 + исправление распределения

## Исправление блока 1 «На распределении»
- Убраны технические маркеры вида `[MAVIS_UNASSIGNED_NOTIFY]` из новых видимых комментариев сделки.
- Старые маркеры всё ещё распознаются для антидубля, поэтому после обновления повторные уведомления не появятся только из-за смены формата.
- Рекомендации строятся только по экспертам отдела Производства.
- Сотрудники продаж не попадают в расчёт загрузки, историю активных экспертов компании и рекомендацию предыдущего эксперта, даже если они числятся ответственными по какой-либо производственной сделке.
- Если `DISTRIBUTION_EXPERT_IDS` задан — он остаётся абсолютным allowlist.
- Если не задан — отдел Производства автоматически определяется по опорным экспертам `2052,1960,2192,2198`; можно заменить через `DISTRIBUTION_EXPERT_SEED_IDS`.

## Блок 5 «Сбор информации»
- 3 календарных дня без полного комплекта документов: клиенту отправляется напоминание по предпочтительному каналу с конкретным перечнем недостающего и указанием почты `mavis.group@mail.ru`.
- Если клиент прислал часть документов, 3-дневный отсчёт начинается заново от последнего входящего комплекта.
- Если сделка сейчас зависит от подбора специалиста, клиентский пуш по документам не отправляется — это обрабатывает блок 6.
- 7 календарных дней на стадии «Сбор информации»: Тане приходит отчёт с экспертом, причиной зависания, полученными и недостающими документами.
- Клиентские и служебные действия выполняются только в рабочее окно Пн–Пт 09:00–18:00 по Минску.
- Новые комментарии человекочитаемые, без технического кода в начале.

## Блок 6 «Подбор»
- Поля `Нужен подбор`, `Способ подбора/Силами кого`, `Кого ищем/Кого подбираем` ищутся динамически по названиям в Bitrix; старые UF-коды оставлены как fallback.
- Если ищет клиент самостоятельно: каждые 7 календарных дней ответственному эксперту ставится задача «уточни, нашли ли людей».
- Если подбор выполняет Mavis: каждые 7 календарных дней ИИгорь читает актуальную воронку «Прорабы» и даёт эксперту до 5 свободных подходящих кандидатов.
- Через 14 календарных дней подбора Mavis Тане приходит отчёт: кого ищем, ответственный эксперт, есть ли сейчас свободные кандидаты.
- Сам блок 6 ничего массово не проставляет в соседние сделки и не запускает глобальное распространение прорабов.
- Старые сценарии `checkCollectionStageStuck` (5/10 дней) и `checkSelectionStage` не запускаются параллельно с новыми блоками 5–6, даже если `STAGE_MONITORING_ENABLED=true`.

## Флаги
По умолчанию:
- `COLLECTION_CONTROL_ENABLED=true`
- `SELECTION_CONTROL_ENABLED=true`
- `COLLECTION_REMINDER_DAYS=3`
- `COLLECTION_LEADER_DAYS=7`
- `SELECTION_EXPERT_EVERY_DAYS=7`
- `SELECTION_LEADER_DAYS=14`

Для короткого теста можно временно использовать:
- `COLLECTION_TEST_MINUTES`
- `SELECTION_TEST_MINUTES`
После теста удалить/поставить 0.
