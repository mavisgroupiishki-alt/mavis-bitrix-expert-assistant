# v82 — надёжное восстановление пушей по актам

Исправления:
- добавлен отсутствовавший маркер ACTS_FILE_PENDING_MARKER (в v81 это могло ронять цикл пушей);
- перед каждым циклом состояния пушей заново сверяются с Bitrix, а не только с памятью Render;
- восстановление задач идёт по CHANGED_DATE и CREATED_DATE с дедупликацией;
- расширен просмотр таймлайна сделки до 300 комментариев;
- любой новый файл в задаче/таймлайне больше не считается автоматически подписанным актом;
- ложные старые SCAN_RECEIVED от «любого нового файла» больше не блокируют пуши;
- новый неизвестный файл ставит пуши на паузу 24 часа, но не завершает контроль;
- в лог добавлены `активных=N, по сроку=M` для быстрого контроля.

Правило пушей не менялось: первый пуш через 2 календарных дня от успешной отправки, Сб/Вс не пишем.
