# v84 — приоритет актуального контакта + обязательная доставка акта

Изменения только в блоке автоотправки актов и последующих пушей.

## 1. Несколько контактов в сделке

Алгоритм:
1. Получает все контакты сделки через `crm.deal.contact.items.get` + `CONTACT_ID`.
2. Если контакт один — использует его.
3. Если контактов несколько — сначала ищет последнюю Wazzup-переписку; затем последнюю другую переписку (email / Viber / Telegram / чат / сообщение), исключая звонки.
4. Если историю определить нельзя или лучший адресат не принял акт, последовательно пробует основной контакт сделки, остальные её контакты и email компании.
5. Отправка не блокируется только потому, что в CRM несколько контактов: система должна использовать каждый доступный адресат и канал до первого успешного результата.

При успешной отправке `contactId` сохраняется в `[MAVIS_ACTS_PUSH_STATE]`.
Все последующие автопуши по акту отправляются тому же контакту, которому ушёл первоначальный акт.

Для старых отправок, где `contactId` ещё не был сохранён, v84 один раз пытается восстановить актуального получателя по последней переписке.

## 2. Жёсткий запрет сообщения без файла акта

До любой отправки клиенту проверяется наличие и доступность файла.

### Viber / Telegram
- реальный файл сначала скачивается из Bitrix и валидируется;
- затем файл сначала успешно отправляется в Wazzup;
- только после успешной отправки файла уходит текст сообщения;
- если подготовка или отправка файла падает — текст НЕ отправляется.

### Email
- требуется attachable Bitrix attachment (`n...`);
- файл дополнительно скачивается/валидируется;
- если вложение невозможно приложить или файл недоступен — письмо НЕ отправляется.

Таким образом клиент больше не должен получить только текст «Направляем акт…» без самого акта.

## Логи

При нескольких контактах:
`[acts-recipient] deal=...: из N контактов выбран Имя (#ID) — последняя переписка activity=...`

Если у сделки вообще нет ни контакта, ни компании с доступным каналом, в таймлайне останется причина сбоя для ручного исправления CRM-данных.
