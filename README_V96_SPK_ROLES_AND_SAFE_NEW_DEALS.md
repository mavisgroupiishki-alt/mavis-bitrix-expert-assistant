# v96 — New Deals Only + clean SPK CJM

Дата сборки: 25.08.2026.

## Безопасность
- CJM обрабатывает только сделки Производства, созданные с `2026-08-25T16:36:00+03:00` по умолчанию.
- Старый env `CJM_GO_LIVE_AT` намеренно не используется, чтобы случайно не вернуть старый cutoff.
- Для явного переопределения используется только `CJM_GO_LIVE_AT_V96`.
- Сделки, созданные раньше cutoff, CJM не трогает даже после движения по стадиям/редактирования.
- Контур актов не изменён.

## Исправления СПК
- В первоначальный «Ход работы» больше не добавляется полный универсальный перечень СПК.
- Автоматическая отправка второго DOCX-перечня отключена.
- В первоначальном «Ходе работы» и напоминаниях на этапе «Сбор информации» не запрашиваются:
  1. свидетельство о регистрации;
  2. устав;
  3. документ на помещение.
  Эти документы сохранены как отдельный будущий этап выезда.
- Книга учёта проверок исключена из обязательного перечня полностью.
- Требования по заверению копий не добавляются в первоначальный «Ход работы».
- Добавлен пост-фильтр: даже если ИИ попытается вставить регистрацию/устав/помещение/книгу проверок/заверение в стартовый СПК-текст, строки удаляются перед отправкой.

## Роли специалистов
Перед формированием «Хода работы» теперь выполняется отдельный структурный разбор расшифровки:
- ФИО;
- официальная должность;
- роль в рамках конкретной услуги;
- короткий фрагмент расшифровки, подтверждающий роль;
- confidence.

Официальная должность и роль по СПК не смешиваются. Пример:
- Гопеев: официально директор → роль по СПК главный инженер;
- Зайцева: официально главный инженер по общестроительным работам → роль по СПК инженер-сметчик.

Если роль не подтверждена в разговоре или уверенность низкая, ИИ не имеет права придумывать её клиенту.
В Render лог пишется строка `[autopilot deal=... roles] ...`, чтобы можно было понять, ошиблась транскрибация или последующий анализ.

## Риски
- ИИ запрещено добавлять гипотетические риски «на всякий случай».
- Риск допускается только если он прямо подтверждён звонком, документами или полями сделки.

## Технические комментарии
- Новые комментарии через `addAutopilotCommentOnce` пишутся человеческим текстом без технического marker-префикса.
- Старые marker-комментарии остаются читаемыми для защиты от дублей.
