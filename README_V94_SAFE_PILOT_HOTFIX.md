# v94 — SAFE PILOT HOTFIX

Срочная безопасная версия после обнаружения исходящих сообщений по старым сделкам.

## Главная защита

По умолчанию `CJM_PILOT_ONLY=true`.
Пока флаг включён, весь CJM может действовать только по `CJM_TEST_DEAL_ID` (по умолчанию 38072, ООО «Бобик»).

Для любых других сделок CJM запрещены:
- клиентские сообщения;
- комментарии/задачи CJM;
- движение стадий;
- контроль документов;
- блоки 5–6;
- распределение;
- propagation на связанные сделки.

Автоматизация актов не отключается и работает своим отдельным контуром.

## Исправления, накопленные в тестах

1. Ход работы без звонка для Бобика — детерминированный тестовый режим.
2. Повторный Ход работы запрещён после успешной отправки без явного reset.
3. Правильное чтение enum-поля «Предпочитаемый канал связи» для Viber/Telegram.
4. После входящего email перед ответом перечитывается полная карточка сделки — выбранный канал больше не теряется.
5. Клиентское название «Аттестация СМР» показывается как «Аттестация».
6. Требование о заверении копий убрано из перечня для текущего CJM.
7. Новые технические `[MAVIS_*]`/JSON-маркеры не выводятся в видимые комментарии CJM; старые читаются только для совместимости.
8. Email polling: быстрый цикл + защита от наложения циклов.
9. Неизвестная услуга больше НЕ получает fallback-перечень «Аттестация». Если услуга не поддержана, CJM молчит.
10. Входящие документы по умолчанию работают только с тестовой сделкой (`CLIENT_DOCS_ALL_DEALS=false`, `CLIENT_DOCS_TEST_DEAL_ID=38072`).
11. Файлы типа «другое»/неизвестные, нечитаемые или low-confidence сохраняются, но не засчитываются в комплект, не сбрасывают срок и не вызывают автоматический ответ клиенту.
12. В pilot-only режиме связанные/старые сделки компании не затрагиваются.

## После деплоя

В startup-логе должны быть:
- `cjmPilotOnly=true`
- `clientDocsAll=false`
- `clientDocsTestDeal=38072`
- `safetyV94=ON`

И при общем цикле:
`v94 SAFETY: pilot-only ON — массовый обход отключён, разрешена только сделка 38072.`

Не устанавливать `CJM_PILOT_ONLY=false` до завершения всех тестов и отдельного согласования боевого запуска.
