# v112 FAST_CACHE — мгновенное открытие отчёта

Что изменено:

- Последний успешно загруженный отчёт сохраняется в браузере (localStorage).
- При следующем открытии данные показываются сразу, без ожидания полной синхронизации с Bitrix24.
- Серверный snapshot теперь тоже отдаётся сразу; если он устарел, обновление запускается в фоне.
- Полная синхронизация с Bitrix24 больше не скрывает уже показанный отчёт.
- Кнопка «Обновить данные» оставляет старые данные на экране, пока идёт тяжёлая синхронизация.
- Автопроверка обновлений — каждые 5 минут.
- Базовый TTL серверного кэша уменьшен с 15 до 5 минут; можно переопределить DOC_RETURN_REPORT_CACHE_SECONDS.

Важно: после абсолютно первого запуска на новом браузере и сразу после чистого деплоя, если ещё нет ни браузерного, ни серверного снимка, первичная сборка всё ещё может занять время. Начиная со второго открытия отчёт показывается сразу.
