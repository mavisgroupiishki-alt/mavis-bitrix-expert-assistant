# v91 — чистый таймлайн CJM + клиентский текст Аттестации

Изменения поверх v90:

1. Новые CJM-комментарии больше не показывают технические маркеры вида `[MAVIS_...]` для:
   - успешного Хода работы;
   - этапа ЛК Белстройцентра;
   - запуска контроля документов;
   - первого контроля/напоминания по документам;
   - входящих документов Аттестации/СПК и ответа клиенту.
   Старые маркеры продолжают читаться для обратной совместимости.

2. В клиентских сообщениях название `Аттестация СМР` отображается как `Аттестация`.
   Внутри CRM исходное название услуги не меняется.

3. Из клиентского перечня документов убрана строка про заверение копий директором.
   То же самое применено к автоматически формируемому DOCX перечню.

4. Контроль ожидания документов теперь сохраняется в таймлайне человеческим текстом:
   `ИИгорь: контроль документов запущен.` + срок и канал, без JSON.

5. Входящие документы Аттестации/СПК сохраняют состояние в читаемом комментарии
   (что распознано / чего не хватает), без технического JSON-маркера.

Следующий тест на Бобике:
- Блок 3: не присылать документы и дождаться тестового напоминания (для deal 38072 — около 2 минут после старта контроля).
- Блок 4: отправить один тестовый PDF/фото документа; ИИгорь должен сохранить, распознать и обновить список недостающего.
- После этого блок 5 проверяется автоматически на неполном комплекте (ускоренный тест Бобика — около 5/8 минут).
