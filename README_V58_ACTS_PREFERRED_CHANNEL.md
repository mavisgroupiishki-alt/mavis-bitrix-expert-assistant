# v58 — акты отправляются по полю «Предпочитаемый способ связи»

## Что изменено

В v57 отправка после стадии задачи «Сделано» была жёстко завязана на Viber.
В v58 логика исправлена:

- если в сделке в поле «Предпочитаемый способ связи» выбран Email / Почта — акт отправляется письмом через Bitrix;
- если выбран Telegram / TG / Телеграм — сообщение и файл акта отправляются через Wazzup Telegram;
- если выбран Viber / Вайбер — сообщение и файл акта отправляются через Wazzup Viber;
- если поле пустое или не распознано — клиенту ничего не отправляется, в сделку пишется причина;
- запасные каналы не используются, чтобы не отправить акт не туда.

## Нужные переменные Render

Обязательные для сценария актов:

ACTS_TASKS_ENABLED=true
ACTS_PROJECT_ID=36
ACTS_RESPONSIBLE_ID=2182
ACTS_SEND_TO_CLIENT_ENABLED=true
PREFERRED_CONTACT_FIELD_CODE=UF_CRM_1781189436900
SERVICE_FIELD_CODE=UF_CRM_1765113071

Для Telegram:

WAZZUP_TG_CHANNEL_ID=...
WAZZUP_TG_CHAT_TYPE=telegram

Для Viber:

WAZZUP_VIBER_CHANNEL_ID=...
WAZZUP_VIBER_CHAT_TYPE=viber

Для Email отдельный SMTP не нужен: письмо создаётся через Bitrix crm.activity.add.

## Роботы Bitrix

1. Сделка производства закрылась успешно:

/api/acts/robot-closed?deal_id={{ID}}

2. Задача в проекте «Акты счета» перешла на стадию «Сделано»:

/api/acts/task-done?task_id={{ID}}

## Тестовая логика

1. Закрыть сделку ООО «Бобик» успешно.
2. Дождаться создания задачи на акт в проекте «Акты счета».
3. Прикрепить файл акта в задачу.
4. Перевести задачу на стадию «Сделано».
5. Проверить, что акт ушёл по каналу из поля «Предпочитаемый способ связи» в сделке.
