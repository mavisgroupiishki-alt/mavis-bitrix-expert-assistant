# v108 — обязательное вложение + окно рассылки 08:00–19:00 Минск

Изменения только для процесса возврата оригиналов.

- Email-only логика сохранена.
- Перед SMTP файл обязателен дважды: в send-context и непосредственно при сборке MIME.
- Готовый MIME дополнительно проверяется: должен содержать `Content-Disposition: attachment` и имя файла.
- В логах успешная подготовка: `[doc-return] ATTACHMENT VERIFIED ...`.
- Если вложения нет / MIME не содержит attachment — письмо НЕ отправляется.
- Авторассылка работает только с 08:00 включительно до 19:00 не включительно по `Europe/Minsk`.
- Вне окна весь цикл doc-return ставится на паузу, задачи не перебираются и письма не отправляются.
- Параметры можно изменить через `DOC_RETURN_SEND_START_HOUR`, `DOC_RETURN_SEND_END_HOUR`, `DOC_RETURN_SEND_TIMEZONE`.
