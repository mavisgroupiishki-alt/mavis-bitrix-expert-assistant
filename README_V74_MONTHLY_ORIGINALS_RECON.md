# v74 — ручная месячная сверка оригиналов актов

Пока автоматический запуск не включается. Сначала тестируем отчёт на реальном месяце.

## Логика
1. CRM Производство (CATEGORY_ID из PRODUCTION_CATEGORY_ID, по умолчанию 28).
2. Только сделки со STAGE_SEMANTIC_ID=S и CLOSEDATE внутри выбранного месяца.
3. Группировка по ASSIGNED_BY_ID (эксперт).
4. Ищем задачу проекта Акты счета #36. Основная связь — UF_CRM_TASK=D_<dealId>.
5. Если CRM-связи нет — осторожный fallback по названию компании/сделки + услуге. Неоднозначные совпадения автоматически не засчитываются.
6. Оригинал есть только если доверенная задача находится в стадии с названием «Архив». ID стадии определяется через task.stages.get.
7. Формируется краткий отчёт для Татьяны.

## Ручной тест
Добавить в Render Environment `ACTS_RECON_TOKEN=<секретная строка>`.
После деплоя открыть:
`https://<render>/api/acts/reconcile?month=2026-08&send=0&token=<секрет>`
`send=0` — только просмотр JSON, Тане ничего не отправляется.
После проверки можно выполнить тот же URL с `send=1`.

Автоматический запуск в последний рабочий день месяца добавляем только после подтверждения ручного отчёта.
