# v88 — надёжный тест «Хода работы» без звонка для ООО «Бобик»

Исправления поверх v87:

1. Сделка 38072 (CJM_TEST_DEAL_ID) ставится первой в каждом цикле автопилота, чтобы не ждать обработки остальных сделок Производства.
2. Тестовый Ход работы Бобика без звонка больше не зависит от ответа ИИ. Он формируется детерминированно из услуги сделки + стандартного перечня документов MAVIS.
3. Для Бобика без звонка автоматически ставится срок +2 календарных дня.
4. Клиентское сообщение по-прежнему дополняется полным конкретным перечнем документов и фразой: «Документы, пожалуйста, направляйте на нашу почту: mavis.group@mail.ru».
5. После успешной отправки сообщение фиксируется в Bitrix, а сделка переводится на «Сбор информации».
6. Задержка между обработкой разных сделок уменьшена с 5 секунд до 0,8 сек; тестовая сделка идёт первой.
7. Боевые сделки по-прежнему требуют нормальный звонок >=60 секунд. No-call fallback относится только к CJM-тестовой сделке.

В startup-логе должна быть строка `noCallDeterministicV88=ON`.
В логе Бобика: `v88 TEST: Ход работы без звонка сформирован детерминированно, без вызова ИИ.`
