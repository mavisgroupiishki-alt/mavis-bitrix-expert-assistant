# v62 — локальная проверка стадии задач актов

- Polling больше не передаёт `STAGE_ID` в фильтр `tasks.task.list`.
- Сначала получает задачи проекта `ACTS_PROJECT_ID`, затем локально сравнивает фактический `STAGE_ID` с найденной стадией «Сделано/Сделаны».
- Если на нужной стадии ничего нет, в лог выводятся последние задачи проекта с `id`, `stage`, `status`, `crm`, `title`.
- Это позволяет сразу увидеть фактический ID стадии конкретной задачи и исключить ложный `0 задач` из серверного фильтра Bitrix.
