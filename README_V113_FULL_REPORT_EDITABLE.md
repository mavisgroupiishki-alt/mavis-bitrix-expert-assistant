# v113 FULL_REPORT_EDITABLE

Локальный отчёт Bitrix24 «Возврат оригиналов» обновлён:

- 3 вкладки: Контроль оригиналов / Отчёт по рассылке / Возвраты и потенциальные возвраты.
- Основные KPI разделены на «ещё не отправлено», «отправлено, но не вернулось», «вернулось».
- «Вернулось» = стадии СКАН ЕСТЬ + Архив.
- Проценты возврата/невозврата считаются от отправленных документов.
- Месячная динамика загружается отдельно и не блокирует отчёт.
- Отчёт по рассылке: отправленные документы, все email, ответы и категории в цифрах и процентах.
- Ответы редактируются прямо в таблице, добавляются новые строки.
- Статья услуги редактируется вручную.
- Возвраты и потенциальные возвраты вынесены в отдельную вкладку.
- Контроль качества базы кликабельный.
- Ручная правка компании/эксперта/статьи услуги сохраняется в Bitrix через служебную задачу.
- Компания в первую очередь определяется по прямому CRM-элементу компании в самой задаче (CO_...), затем по связанной сделке и fallback-логике.
- Быстрый локальный снимок сохранён: при повторном открытии отчёт показывается сразу, обновление идёт в фоне.
