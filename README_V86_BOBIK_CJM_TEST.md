# v86 — ускоренный тест CJM на ООО «Бобик» (deal 38072)

Цель: проверить блоки 1–6 с минимумом ручных действий, не меняя боевые сроки по остальным сделкам.

## Что изменено

- Только для сделки 38072 включён временный CJM-test режим.
- Блок 1 «Не распределенные»: уведомление через 2 минуты вместо 4 рабочих часов.
- Блок 2 «Ход работы»: разрешено использовать последний содержательный звонок >60 сек, даже если он был сделан раньше текущего входа на стадию «Эксперт назначен» и другим экспертом.
- Старые AUTOPILOT_DONE прошлых тестов Бобика не блокируют новый тест. После успешной обработки конкретного звонка записывается marker с activity ID, поэтому тот же звонок повторно не отправится.
- Блок 3: контроль дедлайна документов для Бобика через 2 минуты.
- Блок 5: первый контроль неполного комплекта через 5 минут, уведомление руководителю через 8 минут.
- Блок 6: задача эксперту через 2 минуты, уведомление руководителю через 4 минуты после входа на «Подбор».
- Все остальные сделки продолжают работать по боевым срокам и обычным правилам.

## Переменные

По умолчанию:
- CJM_TEST_MODE=true
- CJM_TEST_DEAL_ID=38072

После завершения теста поставить CJM_TEST_MODE=false либо перейти на следующую боевую версию без тестового режима.

## Минимальный сценарий

1. Оставить Бобика на «Не распределенные» — через ~2 минуты проверить блок 1.
2. Назначить эксперта и перевести на «Эксперт назначен» — новый звонок делать не нужно: ИИ возьмёт последний подходящий старый звонок.
3. Проверить одно сообщение «Ход работы», комментарий в Bitrix и перевод на «Сбор информации».
4. Не присылать документы 2 минуты — проверить блок 3.
5. Для блока 4 один раз прислать тестовый PDF/фото документа от клиента.
6. Оставить комплект неполным — через 5/8 минут проверить блок 5.
7. Для блока 6 заполнить «Нужен подбор», «Способ подбора», «Кого подбираем» и перевести на «Подбор» — через 2/4 минуты проверить задачи/уведомления.
