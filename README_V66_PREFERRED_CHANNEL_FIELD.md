# v66 — реальное поле «Предпочитаемый канал связи»

- Сервер больше не зависит только от двух старых UF-кодов.
- Если код поля не задан, ИИгорь получает `crm.deal.userfield.list` и автоматически находит поле по подписи «Предпочитаемый канал связи» или старому варианту «Предпочитаемый способ связи».
- Поддерживаются прямые значения `Viber / Telegram / Email` и ID enum-значений.
- В лог пишется найденный код поля и распознанный канал, например: `«Предпочитаемый канал связи» UF_CRM_...: значение="Viber" → viber`.
- Безопасный пилот актов остаётся только для сделки 38072, пока явно не включён `ACTS_ALL_DEALS=true`.
