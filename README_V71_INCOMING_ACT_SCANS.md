# v71 — входящие подписанные сканы актов

- Wazzup webhook: входящие Viber/Telegram `image`/`document` обрабатываются независимо от LIVE_CHAT_ENABLED.
- Клиент определяется по телефону через CRM; обрабатываются только сделки, по которым уже есть активный контроль отправленного акта.
- Email: вложения дополнительно проверяются как возврат подписанного акта по адресу отправителя.
- Скан сохраняется в `Акты_<месяц закрытия сделки>/<ответственный эксперт>` и дублируется в папку компании для Wazzup.
- Для email папка компании остаётся за существующим email-модулем, чтобы не создавать второй дубль.
- После успешного сохранения ставится маркер `[MAVIS_ACTS_SCAN_RECEIVED]`, автопуши прекращаются, эксперт получает персональное уведомление в Bitrix.
- Поддерживаемые экспертные папки: Кананович Иоланта, Горбатова Елизавета, Николаева Екатерина, Баженова Мария, Панькова Ольга.
- На старте сервер проверяет, подписан ли Wazzup `messagesAndStatuses` на `/api/wazzup/webhook`.
- Если входящий файл не распознан как подписанный акт, он не останавливает пуши и не раскладывается как акт.
