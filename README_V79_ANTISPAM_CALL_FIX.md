# v79 — hotfix anti-spam + first-call recovery

## Что исправлено

### Ход работы / первый звонок
- Технические ошибки автопилота больше не пишутся в CRM каждые 10 минут. По умолчанию они только в Render logs.
- Если звонок есть, но STT вернул заглушку вроде `Продолжение следует...`, это теперь не ошибка сделки и не повод писать комментарий. ИИгорь молча повторяет попытку позже.
- Для одного звонка ИИгорь сначала ищет встроенную расшифровку в activity Bitrix, затем перебирает доступные аудио URL/файлы и делает повтор STT.
- `AUTOPILOT_TRANSCRIBE_RETRIES` — число попыток на аудиофайл, по умолчанию 2.
- `AUTOPILOT_POLL_INTERVAL_MINUTES` — интервал polling, по умолчанию 10; для теста можно 2.
- Отказ звонка и ошибка отправки клиенту пишутся в CRM максимум один раз, а не каждый цикл.
- Добавлен anti-overlap: новый polling не запускается, если предыдущий ещё работает.

### Прорабы
- Старые переменные Render больше не могут сами включить массовый обход всех сделок.
- Глобальный скан требует НОВОГО явного флага `FOREMAN_ALLOW_GLOBAL_SCAN=true` в дополнение к `FOREMAN_AUTOMATION_ENABLED=true`.
- Автопроставление прораба во все соседние сделки компании требует НОВОГО явного флага `FOREMAN_ALLOW_PROPAGATION=true`.
- Если новые флаги не заданы, массовые действия выключены даже если старые FOREMAN_* переменные остались в Render.
- Точечные robot-linked / robot-closed сохранены.

## Рекомендуемые настройки сейчас
Не задавать или поставить false:
- `AUTOPILOT_TIMELINE_DIAGNOSTICS=false`
- `FOREMAN_ALLOW_GLOBAL_SCAN=false`
- `FOREMAN_ALLOW_PROPAGATION=false`

Для быстрого теста ООО «Бобик» можно временно:
- `AUTOPILOT_POLL_INTERVAL_MINUTES=2`

Все функции v78 (документы, акты, месячная сверка) сохранены.
