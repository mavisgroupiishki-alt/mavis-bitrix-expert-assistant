# v92 — антидубль Хода работы + ускоренный контроль почты

1. Приоритетный CJM-тест больше не очищает in-memory DONE на каждом цикле. Перед запуском Бобика проверяется человеческий маркер `ИИгорь: Ход работы отправлен клиенту.` в таймлайне. Повторный Ход работы возможен только после явного `/api/autopilot/reset/:dealId`.
2. Почта проверяется по умолчанию раз в 1 минуту вместо 5 минут. Первый цикл после старта — через 15 секунд вместо 3 минут.
3. Добавлен anti-overlap для IMAP: второй почтовый цикл не запускается, пока предыдущий не завершён.
4. Интервал можно изменить через `EMAIL_POLL_INTERVAL_MINUTES`, минимум 1 минута.

Важно: текущая почтовая логика обрабатывает непрочитанные письма. Если письмо вручную открыть до того, как сервер его заберёт, оно может быть пропущено. Для теста лучше не открывать письмо в ящике до появления `[email] Письмо от ...` в Render.
