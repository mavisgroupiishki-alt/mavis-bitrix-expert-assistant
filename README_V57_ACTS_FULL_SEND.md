# v57 — полный тест актов: «Сделано» → отправить клиенту в Viber

Добавлено к v56:

1. Когда задача в проекте «Акты счета» переходит на стадию «Сделано», обработчик `/api/acts/task-done` не только пишет комментарий в сделку, но и пытается отправить клиенту:
   - сначала текстовое сообщение на подпись акта;
   - затем файл акта из вложений задачи.

2. Отправка идёт через Wazzup, по умолчанию через Viber.

3. Повторная обработка защищена маркером в таймлайне сделки: если та же задача уже обработана, повторно клиенту ничего не отправляется.

4. Если файл/телефон/Viber не найдены, в сделку пишется комментарий с причиной, но процесс не падает.

## Обязательные переменные Render

```text
ACTS_TASKS_ENABLED=true
ACTS_PROJECT_ID=36
ACTS_RESPONSIBLE_ID=2182
ACTS_SEND_TO_CLIENT_ENABLED=true
ACTS_SEND_CHANNEL=viber
WAZZUP_API_KEY=...
WAZZUP_VIBER_CHANNEL_ID=...
WAZZUP_VIBER_CHAT_TYPE=viber
```

## Хендлер робота в проекте «Акты счета» на стадии «Сделано»

```text
https://mavis-bitrix-expert-assistant.onrender.com/api/acts/task-done?task_id={{ID}}
```

## Ручная проверка

```text
https://mavis-bitrix-expert-assistant.onrender.com/api/acts/task-done?task_id=ID_ЗАДАЧИ_АКТА
```

## Важно

- «Сделано» = акт обработан и файл можно отправлять клиенту.
- «Архив» = физический оригинал акта вернулся.
- В одном запросе Wazzup не смешиваем текст и файл: отправляем сначала сообщение, затем файл.
