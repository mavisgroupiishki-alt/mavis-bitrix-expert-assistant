# v107 — email из чата задачи

Исправление возврата оригиналов:

- процесс остаётся только EMAIL;
- email ищется в CRM, названии/описании, комментариях, **правом чате задачи**, затем в документах;
- сообщения правого чата читаются через `im.dialog.messages.get`;
- если сотрудник вручную написал email в чат задачи и вернул задачу в «Отправлены», автоматизация теперь увидит адрес и продолжит отправку;
- обязательное вложение, правильный телефон, защита от дублей и стадия «Ручная отправка» сохранены.
