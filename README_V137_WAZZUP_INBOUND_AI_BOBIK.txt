MAVIS v137 — WAZZUP INBOUND AI PILOT / BOBIK

Что изменено:
1. Любое реальное inbound-сообщение Wazzup (текст, файл, фото и т.п.) фиксируется до остальных обработчиков.
2. Если сообщение относится к активному контролю акта, в таймлайне сделки создаётся [MAVIS_ACTS_CLIENT_REPLIED] и состояние актового пушинга удаляется.
3. runActsPushCycle и восстановление состояний дополнительно проверяют этот marker. После ответа клиента дальнейшие актовые push по этому контролю запрещены.
4. Для сделки Бобика (по умолчанию ID 38072) добавлен отдельный пилот живого AI-диалога по входящему ТЕКСТУ Wazzup, даже если активного контроля акта нет.
5. AI получает услугу, сделку и историю [MAVIS_LIVE_CHAT], решает reply/human/no_reply и отвечает тем же Wazzup-каналом, откуда пришло сообщение.
6. Для остальных сделок новый AI-fallback не запускается. Их обычные существующие обработчики остаются без изменений.

Render Environment (не обязательно менять, есть безопасные defaults):
WAZZUP_AI_TEST_ENABLED=true
WAZZUP_AI_TEST_DEAL_ID=38072

Проверка:
node --check server.js

Тест:
- деплой;
- убедиться в startup-логе: WAZZUP_INBOUND_AI_V137=ON;
- написать Бобику реальное входящее сообщение через Wazzup;
- ожидать в логах [wazzup-inbound-v137] и [wazzup-ai-v137];
- в сделке 38072 должен появиться [MAVIS_ACTS_CLIENT_REPLIED] (если есть/был актовый контроль) и [WAZZUP_AI_INBOUND];
- при безопасном вопросе должен появиться [WAZZUP_AI_REPLY ...].
