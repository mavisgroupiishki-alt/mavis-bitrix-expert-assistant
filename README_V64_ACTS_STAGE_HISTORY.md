# v64 — надёжный триггер стадии «Сделано»

- Polling больше не зависит от первых 200 задач проекта.
- `tasks.task.list` запрашивает только недавно изменённые задачи проекта по `>=CHANGED_DATE`.
- Если задача уже ушла со стадии «Сделано» к моменту polling, сервер проверяет `tasks.task.history.list` и ищет реальный переход `STAGE_ID -> Сделано`.
- При подтверждённом переходе обработчик акта запускается даже если текущая стадия уже другая.
- Файлы по-прежнему ищутся сначала в задаче, затем в task chat (v63).
- Первый запуск смотрит историю за последние 15 минут, следующие циклы имеют overlap 2 минуты.
