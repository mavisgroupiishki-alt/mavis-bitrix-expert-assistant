# v70 — Автопуши по актам + боевой режим

- Автоотправка актов включена по всей воронке (ACTS_ALL_DEALS по умолчанию true).
- Исторические задачи, которые давно лежат в «Сделано», не рассылаются: polling берёт только новые изменения после ACTS_PRODUCTION_START_ISO (по умолчанию 2026-08-18 14:56 Минск).
- После успешной отправки акта запускается контроль подписанного скана.
- Пуш через тот же канал каждые 2 календарных дня. Если расчётный слот попадает на субботу/воскресенье, он пропускается; следующий слот ещё через 2 календарных дня.
- Пуши прекращаются только после обнаружения нового файла после отправки акта в task chat/таймлайне сделки либо после перехода актовой задачи в «Архив».
- Через 7 календарных дней без скана создаётся задача ответственному по производственной сделке: «Позвонить по акту: ...».
- Состояние пушей фиксируется маркерами в CRM timeline и восстанавливается после перезапуска Render.
- Автоматический сбор сканов из Viber/email в папки — следующий отдельный блок ТЗ.

## Быстрый тест без ожидания 2/7 дней
В Render можно временно задать `ACTS_PUSH_TEST_MINUTES=2` и `ACTS_CALL_TEST_MINUTES=5`. После проверки удалить обе переменные: в бою снова будут 2 календарных дня и 7 календарных дней.
