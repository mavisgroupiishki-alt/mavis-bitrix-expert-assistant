MAVIS — связь «График платежей» → управленческий РНП
Версия bridge v3

Этот архив НЕ является Bitrix local-app ZIP. Это готовые полные файлы для текущего Render-проекта «График платежей».
Ничего вручную дописывать в HTML/JS не нужно.

Заменить в текущем проекте:
  templates/app.html
  templates/revenue.html
Добавить:
  static/rnp-payment-bridge.js

Существующие static/app.js, static/revenue.js, styles.css, app.py и данные pay_schedule НЕ заменяются.

Что происходит после deploy:
1) При первом открытии «Чистой выручки» создаётся/проверяется скрытое множественное CRM-поле XML_ID=MPS_PAYMENT_ROWS.
2) Сразу запускается перенос зеркальной копии ВСЕХ существующих строк pay_schedule по сделкам — без зависимости от BX24.isAdmin().
3) После каждого дальнейшего сохранения графика текущая сделка автоматически синхронизируется в CRM.
4) РНП читает только зеркальную CRM-копию и не требует entity-scope другого приложения.
5) Источник истины остаётся pay_schedule. Зеркальное поле — только read-мост для РНП.

Формат одной зеркальной строки:
  {d: дата платежа, a: сумма клиента, c: подрядчик, o: другой подрядчик, x: расход подрядчика, r: порядок}

Контроль:
- В «Чистой выручке» после первого админского открытия появится служебное сообщение: «РНП подключён к графику платежей…».
- В сделке после сохранения сообщение станет: «... РНП синхронизирован.»

Важно: историческая синхронизация запускается автоматически не чаще одного раза в 6 часов. Текущая сделка синхронизируется сразу после каждого сохранения.

6) В «Чистой выручке» есть кнопка «Синхронизировать РНП» для принудительной полной пересинхронизации.
