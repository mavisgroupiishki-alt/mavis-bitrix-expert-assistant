# ИИ-ассистент эксперта MAVIS GROUP — MVP 1

Серверное локальное приложение Bitrix24 для первого этапа:

- открывается внутри Bitrix24;
- показывает кабинет эксперта;
- эксперт видит сделки, где он указан ответственным;
- администратор/руководитель может видеть все сделки;
- есть кнопка «Проверить передачу»;
- приложение проверяет существующие данные сделки и связанной сделки продаж;
- после подтверждения пишет комментарий в таймлайн и создаёт задачи.

## 1. Установка локально

```bash
npm install
npm start
```

Откройте `http://localhost:3000/health`.

Для Bitrix24 нужен публичный HTTPS URL, поэтому локально приложение только проверяется технически.

## 2. Деплой на Render

- Создайте репозиторий GitHub и загрузите эти файлы.
- Render → New → Web Service → подключите репозиторий.
- Build Command: `npm install`
- Start Command: `npm start`
- После деплоя получите URL вида `https://name.onrender.com`.

## 3. Деплой на Railway

- Railway → New Project → Deploy from GitHub repo.
- Выберите репозиторий.
- Railway сам увидит `npm start`.
- После деплоя получите публичный URL.

## 4. Настройка локального приложения в Bitrix24

В Bitrix24: Приложения → Разработчикам → Другое → Локальное приложение.

Тип: `Серверное`.

Поля:

- Путь вашего обработчика: `https://ВАШ-ДОМЕН/app`
- Путь для первоначальной установки: `https://ВАШ-ДОМЕН/install`
- Название пункта меню Русский: `ИИ-ассистент эксперта`
- «Использует только API»: НЕ отмечать

Права минимум:

- CRM (`crm`)
- Задачи (`task` / `tasks`)
- Пользователи (`user`)
- Диск (`disk`) — желательно
- Звонки (`call`) — желательно
- Открытые линии (`im`, `imopenlines`) — желательно

## 5. Ограничения MVP

На этом этапе ИИ-анализ сделан как первичная проверка по существующим полям, комментариям и активностям. Следующий этап — подключить BitrixGPT/Vibe API или OpenAI API на сервере, чтобы анализ был не эвристическим, а полноценным.

Приложение ничего не отправляет клиентам автоматически и не меняет стадии сделок.
