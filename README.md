# MAVIS Bitrix Expert Assistant — v18 Manager Dashboard

Версия v18 добавляет кабинет руководителя / РОП поверх рабочей логики v17.

## Что есть

- Быстрый список активных открытых производственных сделок.
- Проверка передачи из продаж в производство.
- Формирование хода работы.
- Продуктовая логика по услугам.
- Чек-листы документов.
- Проверка входящих документов/файлов.
- Контроль дедлайнов.
- Новый кабинет руководителя / РОП:
  - ошибки передачи;
  - нужно подтвердить;
  - не проверено;
  - без следующего шага;
  - просрочено;
  - дедлайны на сегодня;
  - сводка по ответственным экспертам;
  - быстрые фильтры проблемных сделок.
