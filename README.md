# MAVIS Bitrix Expert Assistant v3

Серверное локальное приложение Bitrix24 для кабинета эксперта производства.

## Что изменено в v3

- Кнопка «Проверить передачу» стала строже: больше не считает пункт найденным только по случайному слову.
- Результат делится на три блока: «Найдено точно», «Нужно подтвердить», «Не найдено».
- По каждому найденному пункту выводится источник и фрагмент текста.
- Проверяется производственная сделка и связанная сделка отдела продаж, если ссылка распознана.
- Учитываются товары/услуги, комментарии, дела/активности, компания и контакт.
- Задача менеджеру создаётся, если есть отсутствующие или спорные данные.

## Render

Build Command:

```bash
npm install
```

Start Command:

```bash
npm start
```

## Переменные окружения

```env
LEADER_USER_IDS=2110,14,2182
ROP_USER_IDS=2156
ADMIN_USER_IDS=2110,14
MAX_DEALS=50
PRODUCTION_CATEGORY_ID=
```

После того как в таблице приложения увидите ID воронки производства, заполните `PRODUCTION_CATEGORY_ID`.

## URL для локального приложения Bitrix24

Путь обработчика:

```text
https://<render-url>/app
```

Путь установки:

```text
https://<render-url>/install
```
