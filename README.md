# MAVIS Bitrix Expert Assistant v14

v14 добавляет продуктовую логику для формирования хода работы и задач.

## Что изменено

1. Ход работы теперь зависит от значения поля “Услуга”.
2. Добавлены разные сценарии для:
   - СТК / СПК;
   - периодики / подтверждения СТК;
   - аттестации организации;
   - аттестации специалиста;
   - ISO / СУОТ / охраны труда;
   - подбора специалиста;
   - общего сценария, если продукт не распознан.
3. В карточке хода работы добавлен блок “Продуктовая логика”.
4. Блоки “Что делает MAVIS GROUP” и “Что нужно от клиента” теперь формируются под конкретный продукт.
5. При создании задач по ходу работы добавляется продуктовая задача, например:
   - “Сформировать перечень документов для СТК/СПК”;
   - “Проверить исходные данные специалиста для аттестации”;
   - “Собрать исходные данные для ISO/СУОТ”.

## v15
Добавлен продуктовый чек-лист документов и данных: отдельная кнопка, блок в ходе работы и чек-лист в задачах по ходу работы.

## v16
Добавлена проверка входящих документов/файлов по сделке:
- новая кнопка “Проверить входящие документы”;
- ассистент смотрит поля сделки, комментарии, дела/активности и доступные прикреплённые файлы;
- сверяет найденные документы с продуктовым чек-листом;
- показывает “Найдено”, “Нужно проверить вручную”, “Не найдено / запросить у клиента”;
- формирует черновик сообщения клиенту и комментарий в сделку;
- можно создать задачу эксперту на ручную проверку документов.

## v17
Добавлен контроль дедлайнов по сделке:
- новая кнопка “Проверить дедлайны”;
- ассистент анализирует открытые дела, задачи, просрочки, дедлайны на сегодня, элементы без дедлайна и последнюю рабочую активность;
- показывает риски по дедлайнам и рекомендуемые задачи контроля;
- новая кнопка “Создать задачи контроля” создаёт задачи только после подтверждения эксперта;
- задачи привязываются к сделке через UF_CRM_TASK и не дублируются, если похожая открытая задача уже есть.
