# MAVIS Bitrix Expert Assistant v4

Исправления v4:

1. Число сделок теперь явно означает "загружено сделок", а не полный объём в Bitrix. Количество ограничено `MAX_DEALS`.
2. Роль РОП больше не видит все сделки автоматически. Общий просмотр для РОП включается только переменной `ALLOW_ROP_VIEW_ALL=true`.
3. Сделки экспертов фильтруются по `ASSIGNED_BY_ID`, руководители/админы видят все сделки выбранной воронки.
4. Добавлена улучшенная расшифровка стадий: приложение мапит и обычные статусы, и форматы `C28:WON`.
5. "Без следующего шага" проверяет не только CRM-дела, но и связанные задачи через `UF_CRM_TASK`.
6. "Без рабочей активности 2+ дня" считается по последним задачам/делам, а не только по `DATE_MODIFY` сделки.
7. В верхней строке выводится пояснение, какой фильтр и лимит применены.

Render env:

```
LEADER_USER_IDS=2110,14,2182
ROP_USER_IDS=2156
ADMIN_USER_IDS=2110,14
MAX_DEALS=200
PRODUCTION_CATEGORY_ID=
ALLOW_ROP_VIEW_ALL=false
```

Для тестового общего просмотра под Алисой можно временно поставить:

```
ALLOW_ROP_VIEW_ALL=true
```

После определения производственной воронки обязательно заполнить:

```
PRODUCTION_CATEGORY_ID=<ID воронки производства>
```
