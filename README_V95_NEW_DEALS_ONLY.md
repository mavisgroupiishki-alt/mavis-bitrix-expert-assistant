# v95 — CJM только для новых сделок

Боевой hotfix после обнаружения сообщений по историческим сделкам.

## Главное правило

По умолчанию включено:

- `CJM_NEW_DEALS_ONLY=true`
- `CJM_GO_LIVE_AT=2026-08-24T12:37:00+03:00`

CJM имеет право работать только со сделками Производства, у которых `DATE_CREATE >= CJM_GO_LIVE_AT`.

Сделка, созданная раньше cutoff, остаётся исторической навсегда. Её НЕ делает новой:

- перевод на другую стадию;
- изменение полей;
- новое письмо клиента;
- новый комментарий;
- рестарт Render;
- ручной `/api/autopilot/reset/:dealId` — для старой сделки endpoint вернёт 403.

Это сделано специально: старые сделки не должны получать новый «Ход работы», повторный список документов, CJM-напоминания, задачи или движения стадий.

## Что происходит с новыми сделками

Новые сделки после cutoff проходят обычный CJM по поддерживаемым услугам. Старый тестовый режим Бобика при `CJM_NEW_DEALS_ONLY=true` игнорируется, даже если в Render остались старые переменные `CJM_TEST_MODE=true`, `CJM_PILOT_ONLY=true`, `CLIENT_DOCS_ALL_DEALS=false` или `CLIENT_DOCS_TEST_DEAL_ID=38072`.

Входящие документы по Email/Viber/Telegram связываются только с подходящими НОВЫМИ сделками. Если контакт относится только к старой сделке, CJM ничего с ней не делает.

Сопутствующие сделки той же компании также участвуют только если они сами новые. Старая соседняя сделка не комментируется, не двигается и не получает задачу.

## Накопленные исправления v90–v94 сохранены

- корректное enum-поле предпочитаемого канала Viber/Telegram;
- защита от повторного «Хода работы»;
- клиентское название «Аттестация» без «СМР»;
- не просим клиента заверять копии в текущем ходе работы;
- технические `[MAVIS_*]`/JSON не выводятся в новые видимые CJM-комментарии;
- быстрый Email polling и anti-overlap;
- неизвестная услуга не получает fallback-перечень Аттестации;
- нерелевантный/low-confidence файл сохраняется, но не засчитывается в комплект и не запускает клиентский ответ;
- перед ответом после Email заново читается полная сделка и предпочитаемый канал.

## Важно

Автоматизация актов — отдельный контур. v95 не меняет её логику и не ограничивает её cutoff CJM.

`cjmNewDealsOnly=true`
