# v67 — акт: новый текст + реальный формат файла

Изменения:

1. Текст клиенту после готовности акта:
   - просим прислать **скан подписанного акта в течение 2 рабочих дней**;
   - отдельно сообщаем, что **оригинал акта в 2 экземплярах направим почтой**.

2. Исправлена отправка файла через Wazzup:
   - Bitrix `urlDownload` больше не передаётся Wazzup напрямую;
   - сервер сначала скачивает реальные бинарные байты файла из Bitrix;
   - если прямой URL не сработал, используется `disk.file.get -> DOWNLOAD_URL`;
   - вместо HTML/PHP-страницы отправка блокируется с понятной ошибкой;
   - реальный файл на 15 минут публикуется через защищённый случайным токеном endpoint Render;
   - endpoint отдаёт исходное имя и расширение (`.docx`, `.pdf` и т.д.), корректный MIME и `Content-Disposition`;
   - Wazzup получает именно этот URL без редиректа.

3. Размер файла проверяется до отправки: максимум 10 МБ (лимит Wazzup API).

4. Для сообщений по акту используется стабильный `crmMessageId` на задачу, чтобы повторный запрос Wazzup не создавал дубль.

Безопасный режим актов из v65/v66 сохранён: по умолчанию только тестовая сделка `38072`, пока `ACTS_ALL_DEALS=false`.
