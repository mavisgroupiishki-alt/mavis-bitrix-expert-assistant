# v150 — сканы из задач «Акты Счета» на Битрикс Диск

Когда задачу проекта `36` переводят на стадию `СКАН ЕСТЬ` (`1480`), сервис в течение минуты находит прикреплённые к ней файлы и сохраняет их на Общем диске Bitrix.

Путь создаётся автоматически, если его ещё нет:

`Акты/<год>/Акты_<месяц>/Акты <эксперт> <месяц> <год>`

Месяц берётся из даты создания задачи, эксперт — из её постановщика. Каждый успешно сохранённый файл получает технический маркер в комментарии задачи; повторная проверка пропускает такой файл и не создаёт дубль.

Новые переменные не обязательны:

```text
ACTS_TASK_SCAN_ARCHIVE_ENABLED=true
ACTS_TASK_SCAN_ARCHIVE_POLL_INTERVAL_SECONDS=60
```

Для работы нужны существующий `BITRIX_WEBHOOK_URL` с доступом к Задачам, Диску и пользователям. Робот Bitrix и отдельный секрет не используются: сервис опрашивает только недавно изменённые задачи на стадии `1480`.
