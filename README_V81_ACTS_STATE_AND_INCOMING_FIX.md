# v81 — акты: восстановление пушей и защита от ложного напоминания

- Контроль пушей регулярно восстанавливается из Bitrix, а не только один раз после старта Render.
- Старые тестовые маркеры push/scan по той же задаче учитываются только если они появились после текущей отправки акта.
- Если клиент прислал файл, но AI не смог уверенно классифицировать его как подписанный акт (low confidence / technical error), пуш временно ставится на паузу (по умолчанию 24 часа) вместо отправки клиенту ошибочного напоминания.
- Уверенно распознанный счёт/договор/другой документ паузу не создаёт.
- Уверенно распознанный подписанный акт по-прежнему сохраняется и полностью останавливает пуши.

Опционально:
- ACTS_INCOMING_UNCERTAIN_HOLD_HOURS=24
- ACTS_PUSH_STATE_REFRESH_MINUTES=10
