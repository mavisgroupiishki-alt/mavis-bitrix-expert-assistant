# v104 — быстрая очередь + «Ручная отправка»

Изменения:

- polling по умолчанию каждую 1 минуту;
- до 10 действий за цикл вместо 1;
- до 60 проверок за цикл;
- до 3 разных задач обрабатываются параллельно;
- сохраняется защита от дублей внутри каждой задачи;
- автоматически создаётся стадия `Ручная отправка` в проекте #36, если её ещё нет;
- нет email / нет реального файла / внутренний email MAVIS -> письмо НЕ отправляется, задача переводится в `Ручная отправка`;
- в задачу добавляется понятный комментарий с причиной;
- временные SMTP/REST/IMAP ошибки остаются в автоматической очереди и повторяются позже.

## Render Environment (рекомендуемые значения)

```text
DOC_RETURN_POLL_MINUTES=1
DOC_RETURN_MAX_ACTIONS_PER_CYCLE=10
DOC_RETURN_MAX_CHECKS_PER_CYCLE=60
DOC_RETURN_CONCURRENCY=3
DOC_RETURN_MANUAL_STAGE_TITLE=Ручная отправка
```

Если Bitrix начнёт отдавать `QUERY_LIMIT_EXCEEDED`, уменьшить `DOC_RETURN_CONCURRENCY` до 2.
