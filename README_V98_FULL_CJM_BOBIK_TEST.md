# v98 — полный CJM Аттестации + сквозной тест ООО «Бобик»

Основа: v97.

## Безопасность
- Боевой CJM по-прежнему работает только по новым сделкам Производства после cutoff.
- Единственное исключение для старой сделки: тестовая сделка `CJM_TEST_DEAL_ID` (по умолчанию 38072, ООО «Бобик»).
- Остальные старые сделки остаются заблокированы.
- На стадиях Возврат / Работа с возвратом клиентские CJM-автоматизации полностью STOP.

## Бобик
- Новый звонок не нужен.
- Для Бобика ИИгорь ищет уже существующий содержательный звонок по всей истории CRM-сделки.
- Для этого теста не применяется фильтр «звонок после последнего входа на Эксперт назначен» и фильтр по текущему ответственному.
- Требование содержательного звонка/длительности >=60 сек сохраняется.
- Ускоренные интервалы применяются только к тестовой сделке.

## Блок 7 — Обучение
- Дата обучения/экзамена читается из комментариев сделки.
- Эксперту создаётся ровно одно автоматическое напоминание.
- Повторные автоматические напоминания не создаются.
- Для Бобика тестовый порог по умолчанию 2 минуты.

## Блок 8 — Передан оформителю
- Намеренно без автоматизации по бизнес-правилу.
- Эксперт самостоятельно передаёт документы оформителю и двигает сделку.

## Блок 9
- Отдельный контроль бумажных оригиналов не создаётся.
- Стадию меняет эксперт вручную.

## Блок 10 — Замечания
- На стадиях подачи/ожидания решения ИИгорь проверяет входящие email-активности сделки.
- При распознанном замечании пишет комментарий эксперту.
- Один и тот же найденный email не дублируется.
- Клиенту автоматический ответ по замечанию не отправляется.

## Блок 11 — Возврат
- Полный STOP клиентских CJM-сообщений.
- Таня уведомляется один раз.

## Блок 12 — Успешно / реестр
- После ручного перевода экспертом в Успешно ИИгорь проверяет https://att.bsc.by/reestr по УНП компании.
- Боевые сделки: не чаще одного раза в 24 часа.
- Бобик: тестовый интервал по умолчанию 2 минуты.
- После нахождения компании — один комментарий в сделку, без автозаполнения полей.
- Дальше остаётся существующая связка с контуром актов.

## Переменные
- `CJM_BOBIK_TEST_ENABLED=true`
- `CJM_TEST_DEAL_ID=38072`
- `CJM_TRAINING_TEST_MINUTES=2`
- `CJM_REGISTRY_TEST_MINUTES=2`
- `ATT_REGISTRY_URL=https://att.bsc.by/reestr`

## Проверка
`node --check server.js` — успешно.
