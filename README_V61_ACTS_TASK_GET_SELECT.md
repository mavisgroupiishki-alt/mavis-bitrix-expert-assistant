# v61 — исправление CRM-привязки и файлов акта

Причина: `tasks.task.get` не возвращает системные поля `UF_CRM_TASK` и `UF_TASK_WEBDAV_FILES` по умолчанию.

Исправлено:
- `tasks.task.get` теперь явно запрашивает `UF_CRM_TASK`;
- явно запрашивается `UF_TASK_WEBDAV_FILES`;
- в лог добавлены CRM-привязка, найденные dealIds и вложения;
- остальная логика preferred channel не менялась.

Ожидаемый лог после перевода задачи в Сделано:
`[acts] task=46682: CRM=["D_34946"]; dealIds=["34946"]; ...`

После этого должна запускаться отправка по полю «Предпочитаемый способ связи».
