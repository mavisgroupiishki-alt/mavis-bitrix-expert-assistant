# v77 — CJM блоки 1–2: распределение и первый Ход работы

## Блок 1 — На распределении

- контроль только реальной стадии «На распределении»; `C28:NEW` больше не используется как fallback;
- время считается от `MOVED_TIME`, то есть от входа сделки на стадию;
- 4 рабочих часа считаются по Минску, Пн–Пт 09:00–18:00;
- уведомление Тане повторяется не чаще чем раз в 4 рабочих часа, антидубль переживает рестарт Render;
- в рекомендации учитываются активные сделки этой компании, последний эксперт успешной сделки и NPS;
- для нового клиента/когда нет явного прежнего эксперта ИИгорь считает текущую загрузку экспертов по открытым сделкам Производства и рекомендует наименее загруженного;
- можно задать точный состав экспертов через `DISTRIBUTION_EXPERT_IDS=2052,1960,2192,2198`. Если переменной нет, состав определяется по текущим ответственным активных сделок Производства.

### Короткий тест
Временно задать `UNASSIGNED_TEST_MINUTES=2`, поставить тестовую сделку на «На распределении» и проверить сообщение/задачу Тане. После теста удалить переменную.

## Блок 2 — первый звонок и Ход работы

- звонок до передачи сделки эксперту игнорируется;
- если длительность известна и меньше 60 секунд — звонок не запускает Ход работы;
- короткое служебное касание/«перезвоните позже» не запускает Ход работы;
- если звонок не найден или не подходит, сделка остаётся доступной для следующего цикла;
- ошибка отправки клиенту больше не помечает автопилот выполненным: ИИгорь повторит попытку;
- при нескольких сделках одной компании клиент получает одно объединённое сообщение; комментарий/задача фиксируются в каждой связанной сделке;
- если эксперт не назвал срок документов — срок ровно +2 календарных дня;
- клиент всегда получает конкретный стандартный перечень документов по продукту;
- фразы «иные документы из обязательного перечня», «остальные необходимые документы» и подобные удаляются;
- документы клиенту предлагается направлять только на `mavis.group@mail.ru`;
- сообщение и полный отчёт записываются в таймлайн сделки;
- переход на «Сбор информации» выполняется только после успешной отправки клиенту.
