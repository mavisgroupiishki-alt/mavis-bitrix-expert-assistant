# v119 — быстрый точный подсчёт рассылки

- Исправлена ключевая ошибка: рассылка больше не зависит от года создания задачи. В подсчёт попадают старые задачи (в том числе созданные в 2025), если письмо было отправлено в текущей кампании.
- Старт кампании по умолчанию берётся из DOC_RETURN_PRODUCTION_START_ISO (fallback 24.08.2026 13:22 Минск), а не с 26 августа.
- Факт письма по-прежнему строгий: только служебный комментарий «Автоматическое напоминание №…» + «Отправка подтверждена почтовым сервером».
- Скан идёт только по задачам проекта, изменённым после старта кампании/последнего скана.
- Карточки обновляются частично по мере нахождения писем, а не стоят на 0 до конца.
- После первого точного подсчёта один снимок сохраняется в служебной задаче Bitrix; следующие открытия и deploy не требуют полного пересчёта.
