# v122 — Active production match fix

Исправлено занижение количества во вкладке «Невозвраты · активное производство».

В v121 строки без прямого COMPANY_ID в задаче «Акты Счета» отбрасывались, даже если компания была доступна через связанную CRM-сделку. v122 восстанавливает COMPANY_ID через dealId точечно и только для кандидатов на невозврат.

Логика комментария не изменена: комментарий копируется в задачу, дедлайн +14 календарных дней, стадия «Звонок».
