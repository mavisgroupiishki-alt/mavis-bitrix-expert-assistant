# v117 — строгий отчёт по рассылке + быстрый график

- «Отправлено документов» = уникальные задачи, где найдено служебное сообщение «Автоматическое напоминание №1/№2 ... отправлено» И «Отправка подтверждена почтовым сервером».
- «Писем отправлено всего» = количество таких подтверждённых отправок.
- Стадия «Эл. Почта» или «Звонок» сама по себе больше не считается отправкой.
- Проверяются обычные комментарии задачи и, если там метки нет, чат задачи.
- По умолчанию учитывается рассылка с 26.08.2026; дата задаётся DOC_RETURN_MAILING_START.
- Для скорости сканируются только задачи, изменённые после старта кампании; весь старый архив не обходится.
- Вкладка рассылки использует уже готовый снимок отчёта и не запускает тяжёлую полную сборку.
- График динамики остаётся быстрым и строится без полного обхода истории.
