# v87 — CJM Бобик без звонка

Тестовый режим для сделки 38072, чтобы проверить CJM 1–6 с минимумом ручных действий.

## Главное
- Только для сделки `CJM_TEST_DEAL_ID` (по умолчанию 38072) Ход работы можно сформировать без звонка.
- Боевые сделки по-прежнему требуют содержательный звонок >=60 сек.
- Если звонка нет, ИИ формирует стартовый Ход работы только из данных сделки, комментариев и стандартного перечня документов.
- ИИ запрещено писать клиенту «по итогам разговора», «как договорились» и придумывать факты.
- Дедлайн при отсутствии звонка: +2 календарных дня (в тестовом контуре последующий контроль ускорен по правилам v86).
- После успешной отправки Хода работы запускаются прежние блоки контроля документов, входящих файлов, зависания и подбора.

Переменная при необходимости:
`CJM_TEST_ALLOW_NO_CALL=true`

После завершения теста: `CJM_TEST_MODE=false` (или `CJM_TEST_ALLOW_NO_CALL=false`).
