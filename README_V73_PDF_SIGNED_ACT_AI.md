# v73 — распознавание подписанных актов в PDF

- PDF из Viber/Telegram/почты передаётся ИИ целиком как file input.
- ИИ должен отличать подписанный акт от счёта, договора, накладной и других документов.
- Неподписанный акт не считается возвратом.
- Только medium/high confidence + isSignedAct=true останавливает пуши и запускает раскладку.
- При ошибке AI действует fail-closed: файл не раскладывается, пуши не прекращаются.
- JPG/JPEG/PNG/WEBP продолжают проверяться визуально.
