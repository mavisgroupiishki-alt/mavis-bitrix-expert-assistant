# v59 — автопилот ищет тестовую сделку по текущей стадии

Исправлена причина, по которой ООО «Бобик» не попадало в фоновый автопилот, если сделка была создана/переведена на стадию больше 24 часов назад.

Что изменено:
- убран фильтр `>=MOVED_TIME` из тестового поиска автопилота;
- при `EXECUTOR_TEST_DEAL_ID=34946` автопилот ищет именно сделку 34946 на стадиях «Эксперт назначен» / «Сбор информации» независимо от даты;
- старые сделки не запускаются массово: если тестовый ID не задан, цикл не обрабатывает все сделки сам по себе;
- массовый режим возможен только при явном `EXECUTOR_ALL_DEALS=true`;
- защита от повторной обработки через маркер `[MAVIS_AUTOPILOT_DONE]` сохранена.

Для текущего теста Render должен содержать:

```
EXECUTOR_TEST_DEAL_ID=34946
EXECUTOR_ALL_DEALS=false
AUTOPILOT_ENABLED=true
```

После деплоя в логах ожидается строка вида:

```
[autopilot] Тестовый режим: ищу сделку ID 34946 по текущей стадии без ограничения 24 часа.
[autopilot] Цикл: найдено 1 сделок ... для тестовой сделки ID 34946.
```
