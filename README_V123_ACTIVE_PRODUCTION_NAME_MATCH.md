# v123 — Active production name match

Во вкладке «Невозвраты · активное производство» сопоставление теперь идёт в два этапа:

1. Сначала по прямому COMPANY_ID / CRM-связке.
2. Если связки нет или по ней ничего не найдено — по названию компании из отчёта/задачи и TITLE активной сделки Производства.

Приоритет всегда остаётся за точной CRM-связкой. Сопоставление по названию используется как fallback для старых и ручных задач.
