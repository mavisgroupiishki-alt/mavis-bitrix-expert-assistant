# v54 — несколько прорабов в одной производственной сделке

## Что исправлено

В старом поле `Специалист` Bitrix хранит только одно значение, поэтому при выборе второго прораба первый заменяется.

v54 поддерживает новое множественное поле, например `Специалисты/Прорабы`, и добавляет прораба к уже выбранным, а не затирает старого.

## Важные переменные Render

После создания нового множественного поля в Bitrix нужно заменить код поля:

```env
FOREMAN_PRODUCTION_SPECIALIST_FIELD=UF_CRM_XXXXXXXXXXXX
FOREMAN_PRODUCTION_SPECIALIST_FIELD_MULTIPLE=true
```

Старые переменные оставить:

```env
FOREMAN_CATEGORY_ID=32
FOREMAN_STAGE_BUSY=C32:PREPAYMENT_INVOIC
FOREMAN_PROPAGATE_TO_COMPANY_DEALS=true
FOREMAN_AUTOMATION_ENABLED=false
FOREMAN_SUGGESTION_SCAN_ENABLED=false
FOREMAN_ADD_PROPAGATION_COMMENTS=false
FOREMAN_SKIP_PROPAGATED_WEBHOOK_MINUTES=20
```

## Логика

- Если эксперт выбрал 2+ прорабов в сделке производства, ИИгорь переводит каждого из них в `Занят`.
- В карточку каждого прораба пишет комментарий, к какой производственной сделке он привязан.
- В активные сделки этой же компании ИИгорь добавляет этих же прорабов в множественное поле, не удаляя уже выбранных.
- При закрытии производственной сделки ИИгорь проверяет каждого выбранного прораба отдельно.
