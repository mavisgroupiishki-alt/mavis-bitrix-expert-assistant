# v121 — Невозвраты · активное производство

Добавлена отдельная вкладка в отчёт «Возврат оригиналов»:

- показывает только документы, которые уже отправлены и ещё не вернулись;
- оставляет только компании, у которых есть активная сделка в воронке Производство (категория 28 по умолчанию);
- фильтры: год, месяц, даты, компания, эксперт, стадия документа, тип, просрочка, поиск;
- показывает активную сделку производства, её стадию и ответственного;
- поле комментария по каждой строке;
- кнопка «Сохранить и поставить звонок» выполняет в задаче проекта «Акты Счета»:
  1. дедлайн +14 календарных дней;
  2. перевод на стадию «Звонок» (1128);
  3. комментарий `Скопировано из отчета: <текст>`.

Новые переменные Render не требуются. При необходимости можно переопределить:
- DOC_RETURN_PRODUCTION_CATEGORY_ID
- DOC_RETURN_CALL_STAGE_ID
