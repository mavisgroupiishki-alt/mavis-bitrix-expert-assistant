# v80 — автопилот по всем сделкам

Изменения:

- Убрано ограничение `EXECUTOR_TEST_DEAL_ID` для фонового автопилота.
- При `AUTOPILOT_ENABLED=true` ИИгорь проверяет все подходящие сделки Производства на целевых стадиях.
- `EXECUTOR_TEST_DEAL_ID` и `LIVE_CHAT_TEST_DEAL_ID` больше не ограничивают поиск сделок для Хода работы.
- Сбор входящих документов Аттестации/СПК также работает по всем активным подходящим сделкам.
- Сохраняются антидубли v79: параллельные polling-циклы не запускаются, повторяющиеся технические ошибки не спамят таймлайн, один и тот же результат по звонку не должен записываться повторно.
- Блок актов и ежемесячная сверка не менялись.

## Render

Для работы нужен `AUTOPILOT_ENABLED=true`.

`EXECUTOR_TEST_DEAL_ID` можно оставить или удалить — на охват автопилота он больше не влияет.
`EXECUTOR_ALL_DEALS` и `CLIENT_DOCS_ALL_DEALS` также больше не нужны для включения массового режима: в v80 он включён в коде.

Аварийно остановить фоновый автопилот можно `AUTOPILOT_ENABLED=false`.
